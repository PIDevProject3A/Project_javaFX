```

│ [ English  ]  [ Français ]       [  🌙  ]     │
│  ^^^^^^^^    ^^^^^^^^^^^^         ^^^^^^      │
│  Blanc/vert  Gris/texte          Gris       │
│  (active)    (inactive)          (bouton)    │
└────────────────────────────────────────────────┘

Style:
- Background: #F3F4F6 (gris clair)
- Langue active: Blanc + texte vert
- Langue inactive: Transparent + texte gris
- Thème: Gris avec bordure subtile
```

```

Style Dark:
- Background: rgba(51, 65, 85, 0.4) (sombre)
```
